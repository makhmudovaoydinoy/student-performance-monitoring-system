# Talabalar o‘zlashtirishini kuzatish va erta ogohlantirish tizimi

## Loyiha haqida
Ushbu loyiha talabalar o‘zlashtirish ko‘rsatkichlarini kuzatish, davomat va baholarni tahlil qilish hamda o‘zlashtirishda muammoga duch kelishi mumkin bo‘lgan talabalarni erta aniqlash uchun ishlab chiqilgan.

## Asosiy imkoniyatlar
- Talabalar ma’lumotlarini boshqarish.
- Guruhlar va fanlarni boshqarish.
- Talabalar baholarini kiritish va kuzatish.
- Davomatni qayd etish.
- O‘zlashtirish ko‘rsatkichlarini tahlil qilish.
- Xavf guruhidagi talabalarni aniqlash.
- Hisobotlarni ko‘rish.
- Foydalanuvchilar va rollarni boshqarish.

- HTML, CSS, JavaScript
